Recommended Exponential Backoff Formula

Prevents thundering herd on saturated AI clusters by injecting uniform random jitter. 

import random, time

def compute_backoff(attempt, base=1.5, factor=2.0, max_delay=30.0, jitter=1.0):
    return min(max_delay, base * (factor ** attempt) + random.uniform(0, jitter))
